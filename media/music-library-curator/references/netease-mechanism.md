# 网易云音乐云盘 · 歌词与封面机制

> 整理自网易云官方社区 topic《「网易云音乐云盘」相关技巧及其答疑 V2.0.1》
> （music.163.com/web/pctopic?id=18356075）及多个版本客户端的技术分析。

## 一、云盘是什么

> 云盘就是把本地音乐储存云端的工具，类似于以网络数据为载体的 USB。
>
> 云盘的作用是储存云音乐不存在、或因版权下架的歌曲。云盘中的音乐可以匹配到
> 网易云音乐的曲库，成功匹配后，就能欣赏到歌曲的歌词和封面，并且免费试听、
> 下载、收藏。

**关键词**：云盘歌曲本质是「托管资源」，不是本地媒体文件。

## 二、上传限制

| 端 | 能否上传 | 说明 |
|---|---|---|
| PC 客户端 | ✅ | 支持批量拖拽，成功率最高 |
| Android | ✅ | 需授予存储/媒体权限 |
| iOS | ❌ | 系统限制 |
| Mac | ❌ | 仅播放 |
| 网页版 | ❌ | 仅播放 |

**格式白名单**：MP3、FLAC、WAV、M4A、APE 等音频格式。
**`.lrc` 不在白名单** —— 文件选择器不接受，客户端也不做歌词文件绑定。

**单文件上限**：约 300 MB（部分版本 200 MB）。

**M4A 附加条件**：必须未加密。Apple Music 下载的 DRM 文件无法上传。

## 三、歌词来源与优先级

平台处理上传音频的流程：

```
接收上传请求
  → 解析音频文件头（FFmpeg 或自研解码器）
  → 提取标题 / 歌手 / 专辑（ID3 TIT2 / TPE1 / TALB 或等价字段）
  → 检查是否存在 SYLT / USLT 帧（或等价容器字段）
  → 若无内嵌歌词，调用歌词匹配服务（基于声纹或元数据指纹）
  → 匹配失败则标记为「无歌词」
```

三条歌词来源，按可靠性排序：

| # | 来源 | 可靠性 | 说明 |
|---|---|---|---|
| 1 | **内嵌标签** | 高（取决于平台解析实现） | 云盘歌曲走独立缓存机制，绕过标准本地播放器路径，部分实现会无视此标签 |
| 2 | **同名 `.lrc` 侧车** | 中高（需走本地导入路径） | 官方文档明确支持 |
| 3 | **平台曲库匹配** | 取决于曲库覆盖 | 曲库没有 = 必然失败 |

## 四、侧车方案（`.lrc` 无法上传时的正解）

`.lrc` 的正确用法**不是上传**，而是**在本地被客户端读取**。

官方原文：

> 1，保证**歌词（lrc）、封面（jpg，png 等）、歌曲（mp3，wma，flac，ape，wav 等）
>    的文件标题一致**。（注：歌词，封面，歌曲的文件后缀没有必要按照我举例的
>    文件后缀一样，只要保持文件名一致即可）
> 2，打开播放列表 → 点击清空 → 点击清空播放列表。
> 3，将所有的文件全部选中，一起拖拽到播放列表（歌曲会自动播放）→ 收藏到某一个歌单。
> 4，进入相应的歌单 → 右键点击 上传到云盘 → 等待转码。
> 5，这样就可以看到封面，歌词，歌曲。

**要点**：客户端在**扫描本地音乐**时就把同目录同名 `.lrc` 读进歌曲元数据，
之后从歌单上传到云盘时，歌词随音频一起走。所以 `.lrc` 从不需要单独上传。

### `.lrc` 格式要求

| 要求 | 说明 |
|---|---|
| 编码 | **UTF-8 无 BOM**。ANSI(GBK) 会乱码或整段不显示 |
| 时间轴 | 必须有，否则歌词不滚动 |
| 首行 | 不能是空行，必须有内容 |
| 时间戳 | 一行一个时间戳，不能一行多个 |
| 内容 | 不能含敏感词，平台会检测 |

纯音乐（无时间轴）可以只有纯文本。

## 五、匹配曲库的正确率技巧

官方给出的提升成功率要点：

1. 歌曲从网易云官方下载（可秒传）
2. 非官方下载时，**ID3 必须与云音乐曲库信息一致**——尤其歌手、歌名、专辑三项
3. 删除多余的年份、流派、音轨号、Album Artist、Composer、Disc Number
4. 删除封面的「封面描述」

**PC 端上传本地歌曲到云盘匹配词图成功几率更高。**

## 六、歌词匹配的三个层级

云盘匹配原理：**MD5 → ID3 → 听歌识曲**。

| 层级 | 依据 | 失败场景 |
|---|---|---|
| MD5 | 文件哈希与曲库音源完全一致 | 从其他平台下载的文件必然不同 |
| ID3 | 标题 + 歌手 + 专辑 匹配曲库 | 元数据写法不一致（繁简差异、多余符号） |
| 听歌识曲 | 声纹指纹 | 压缩失真影响特征提取精度 |

**曲库不存在该歌时，三级全部失败** —— 这时歌词只能来自文件自身。

## 七、常见失败诊断

| 症状 | 原因 | 处理 |
|---|---|---|
| 上传后无歌词，歌手灰色、专辑空白 | 曲库匹配全失败 | 用内嵌标签 + 同名侧车，走本地导入路径 |
| 改了元数据仍匹配不上 | ID3 与曲库写法不一致（繁简、多余符号） | 对照曲库页面逐字对齐 |
| 侧车 `.lrc` 无效 | 编码非 UTF-8 无 BOM | 另存为时选 UTF-8 |
| 歌词不滚动 | LRC 无时间轴 | 补时间轴 |
| 手机端歌词几天后消失 | 客户端缓存/路径问题 | 重新上传 |
| 换了存放目录歌词消失 | 客户端依赖上传路径 | 路径变更后必须重新上传 |

## 八、歌词共建（让所有人都能看到）

仅适用于自己名下发行且曲库已有的曲目：

| 端口 | 入口 | 要求 |
|---|---|---|
| 手机端 | 歌曲黑胶页 → 百科 → 全部 → 参与共建 | 粘贴 LRC 或在线打时间轴 |
| 网页版 | 播放页 → 更多 → 上传歌词 | 导入本地 LRC 文件 |
| 音乐人后台 | 作品管理 → 单曲编辑 | 仅限自己名下发行曲目 |

需标准时间轴 `[分:秒.毫秒]`，顺序不可颠倒，无违规文字与广告。审核时长 1–3 个工作日。
第三方版权曲目在版权方关闭共建权限时，入口直接隐藏。

## 九、实测结论（2026-10）

对 GAI《REAL G》(2026) 的验证：

- 网易云曲库**无**《REAL G》专辑（`artist/albums/1211046` 返回的 80 张专辑中不含）
- 搜「赢」单曲零命中 → 三级匹配必然全部失败
- 该专辑在 QQ 音乐 / 酷狗 / 酷我 / 咪咕有正版 → 想要省事直接用这些平台的客户端下载

**结论**：曲库没有的专辑，网易云云盘的歌词**只能靠内嵌标签或侧车**，
且必须走「本地导入 → 上传到云盘」路径才有较大希望。
